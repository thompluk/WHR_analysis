Kesejahteraan kini tidak lagi diukur semata dari indikator ekonomi (PDB), melainkan melalui pendekatan yang lebih luas terkait kualitas hidup masyarakat global. World Happiness Report (WHR) hadir sebagai standar acuan internasional untuk mengukur evaluasi kehidupan (Life Evaluation) lintas negara.

Proyek ini bertujuan untuk menganalisis faktor-faktor penentu yang memengaruhi tingkat kebahagiaan di berbagai negara menggunakan dataset World Happiness Report, serta menggali hubungan antara indikator sosial-ekonomi dengan skor kebahagiaan masyarakat.
